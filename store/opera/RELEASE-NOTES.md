# iShield Extension 1.0.0.1 — Opera release notes

Initial Opera Add-ons release.

- blocks ads and trackers with Manifest V3 rules;
- cosmetic and packaged anti-adblock filtering;
- local phishing, scam and malware protection;
- fingerprint-protection controls;
- site allowlist and Strict controls;
- local protection activity counters;
- signed filter-only remote updates;
- no account, analytics, telemetry, managed-device control or browsing-data upload.
