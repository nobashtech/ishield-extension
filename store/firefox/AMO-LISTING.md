# iShield Extension — Firefox Add-ons Listing

## Name
iShield Extension

## Summary
Block ads, trackers, phishing, scams and malware with fast on-device protection and signed filter updates.

## Description
iShield Extension is a privacy-focused protection extension for Firefox. It blocks advertising and tracking requests, removes supported page clutter, helps identify phishing and scam pages, blocks known malicious destinations, reduces common fingerprinting techniques, and includes breakage protection for supported sites.

Protection runs on your device using Firefox WebExtension APIs, packaged filtering code, and local rule lists. iShield Extension does not require an account and does not send your browsing history, visited URLs, page content, search terms, extension analytics, telemetry, device identifiers, or installation identifiers to us.

Filter lists can be refreshed from iShield Extension's fixed update endpoint. Updates contain signed network-rule data only. The extension verifies these rules locally and does not download executable JavaScript, WebAssembly, or feature logic.

### Main features
- Ad and tracker blocking with Firefox Declarative Net Request
- Cosmetic filtering and packaged anti-adblock scriptlets
- Phishing, scam and malware protection
- Fingerprinting protection
- YouTube and Facebook page-level protection where supported
- Per-site controls and allowlist
- Balanced, Strong and Maximum protection modes
- Local activity and blocked-item counters
- Signed filter-rule updates
- No account, telemetry, analytics, managed-device controls or cloud profile
- Private browsing disabled in this release
