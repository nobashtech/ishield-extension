# iShield Extension 1.0.0.1 — Firefox Release Notes

Initial Firefox desktop release.

- Blocks ads and trackers with local DNR filtering.
- Provides packaged cosmetic filtering and anti-adblock scriptlets.
- Adds phishing, scam and malware protection.
- Includes fingerprinting and supported social/video page protections.
- Adds local per-site controls, protection modes and activity counters.
- Supports cryptographically signed filter-rule updates.
- Does not include accounts, telemetry, analytics, managed-device controls or remote executable code.
- Private browsing is disabled in this release.
