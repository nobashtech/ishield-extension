iShield Extension Privacy Policy for Microsoft Edge

Effective: October 5, 2026

This policy applies specifically to the iShield Extension extension distributed for Microsoft Edge.

Privacy by design

iShield Extension is a browser protection extension. It blocks ads and trackers, applies page-cleanup filters, detects suspicious pages, and provides local protection controls and statistics. These features require limited access on your device to information such as the current page URL or hostname, page content needed for protection checks, and network-request metadata exposed by Microsoft Edge extension APIs. iShield Extension processes this information locally. It does not require an account and does not include advertising analytics, telemetry, managed-device enrollment, cloud policy synchronization, remote browsing-history sync, or user profiling.

Information iShield Extension does not upload

  • Browsing history or lists of websites visited
  • Visited URLs, page content, or search terms
  • Form entries, passwords, authentication information, or personal communications
  • Financial or health information
  • Precise location
  • Device or installation identifiers
  • Extension analytics, telemetry, or advertising identifiers
  • User-created allowlists, Strict rules, or local activity records

Local processing and local storage

iShield Extension locally handles browsing activity and limited website content only to provide its user-facing protection features. It may process or store the current tab URL/hostname and page signals needed for protection checks; protection settings and filter preferences; user-created allowlist and Strict-rule hostnames; local protection counters and timestamps; bounded local activity categories/counts; local breakage-recovery hostnames; and the last verified signed filter update.

For phishing, scam, and malware warning flows, iShield Extension may temporarily keep the exact challenged URL in browser session storage so you can go back or continue. This value is not uploaded, is not used to build a remote browsing profile, and expires or is cleared with the browser/extension session. Persistent activity records do not retain a full visited-URL history. You can clear iShield Extension's local data from the extension controls or by removing the extension.

InPrivate browsing

iShield Extension is packaged with InPrivate browsing disabled. It does not run content protection, local activity recording, or filter-update logic in InPrivate sessions.

Filter-list updates

iShield Extension periodically performs a generic HTTPS GET to https://update.broxme.com/ishield/manifest.json only to download signed blocking filters. It sends no browsing history, visited URLs, page content, search terms, device ID, installation ID, account ID, telemetry, analytics, or user-specific request body. Credentials are omitted, no referrer is sent, and redirects are rejected.

The extension accepts exactly one signed network-rules resource. Remote rules are restricted to host/resource-type blocking filters and are compiled by code packaged with the extension. Remote JavaScript, WebAssembly, or other executable extension code is not downloaded or executed. Ordinary network connection metadata, such as an IP address and standard HTTP/TLS connection information, may necessarily be visible to the update server or network while delivering the HTTPS response; iShield Extension does not add a user or installation identifier to the request.

Packaged page protection

iShield Extension includes packaged filtering and scriptlet logic used to block or modify unwanted page behavior. These scripts are part of the submitted extension, not remotely downloaded code. The Edge release excludes imported raw filter rules that actively initiated their own network requests. Remaining page-protection logic is used to block, suppress, or locally modify site behavior as part of the extension's disclosed protection purpose.

Sharing and sale

iShield Extension does not sell user data. It does not send extension user data to advertisers, data brokers, analytics providers, or other third-party data services. Browsing information handled for protection remains on your device.

Permissions

Broad HTTP/HTTPS site access is required for ad/tracker blocking and page protection. Declarative Net Request performs network filtering, scripting runs packaged protection scripts, storage keeps local settings and protection state, alarms schedule signed filter-update checks, and activeTab supports user-initiated current-tab protection statistics. iShield Extension does not request the optional Declarative Net Request feedback permission in the store build.

Remote code

All executable extension logic is packaged with the version submitted to Microsoft Edge Add-ons. Filter updates are narrowly validated structured data applied by packaged code.

Your controls

You can disable iShield Extension protection, allowlist sites, adjust protection settings, clear local extension data where provided, or remove iShield Extension from Microsoft Edge. Removing the extension removes its extension-managed local storage according to Microsoft Edge behavior.

Changes

If iShield Extension's data practices change in a future Edge release, this policy and Microsoft Edge Add-ons disclosures will be updated before the changed behavior is released.

Contact

For privacy questions, use the contact information on the official iShield Extension website.
