# iShield Extension for Firefox

Manifest V3 Firefox package. Runtime behavior is local-only except for a generic HTTPS GET used to download signed filter-list updates from `https://update.broxme.com/ishield/manifest.json`. No browsing data, page content, URLs, hostnames, device identifiers, account data, analytics, or telemetry are transmitted by iShield. The AMO data-collection declaration is `none` because no extension user data is collected or transmitted for storage or processing outside the extension.
