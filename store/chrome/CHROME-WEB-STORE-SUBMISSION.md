## Product name

iShield Extension

## Short description

Fast ad and tracker blocker with phishing, scam and malware protection. Filtering runs on your device, with no account or tracking.

## Single purpose

iShield Extension protects web browsing by blocking ads and trackers, cleaning intrusive page elements, and warning about phishing, scam, and malware risks. Protection is processed locally in the browser. The only extension-originated remote request downloads signed blocking-filter updates.

## Detailed store description

iShield Extension is a privacy-focused browser protection extension for faster, cleaner, and safer everyday browsing.

Core protection includes:

- ad and tracker blocking using Manifest V3 Declarative Net Request rules;
- cosmetic page cleanup for intrusive ad elements;
- packaged anti-adblock and site-specific filtering scriptlets where required by filter lists;
- phishing, scam, and malware warning checks processed locally in the browser;
- YouTube and Facebook ad-cleanup support;
- fingerprint-protection controls;
- allowlist and Strict controls for sites you choose;
- local protection activity and blocked-item statistics;
- signed filter-list updates to keep blocking rules current.

iShield Extension does not require an account. Browsing history, visited URLs, page content, search terms, form data, passwords, device identifiers, installation identifiers, analytics, and telemetry are not uploaded by iShield.

The extension periodically makes a generic HTTPS GET request to https://update.broxme.com/ishield/manifest.json only to obtain signed filter-list data. The update channel cannot deliver JavaScript or other executable extension logic. All executable extension code is packaged in the Chrome Web Store submission.

Private/incognito browsing is disabled for iShield.
