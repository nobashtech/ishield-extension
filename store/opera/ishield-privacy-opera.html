iShield Extension for Opera Privacy Policy

Effective: October 5, 2026

iShield Extension is designed to provide ad, tracker and browser-safety protection while keeping browsing information on the user's device.

Local processing

To provide its protection features, iShield Extension may locally process the current page URL or hostname, limited page content needed for cosmetic filtering or security checks, browser filtering events, the user's protection settings, allowlist/Strict choices, and local blocked-item counters. This processing takes place in the browser.

What iShield Extension does not upload

iShield Extension does not upload browsing history, visited URLs or hostnames, page content, search terms, form entries, passwords, cookies, account information, device identifiers, installation identifiers, advertising identifiers, analytics, or telemetry to Broxme or another backend service.

No account or remote profile

iShield Extension does not require an account and does not create a remote user, device, or installation profile.

Filter updates

iShield Extension periodically makes a generic HTTPS GET request to https://update.broxme.com/ishield/manifest.json to check for signed blocking-filter updates. The request contains no iShield Extension request body, no iShield Extension user or device identifier, omits credentials, rejects redirects, and uses a no-referrer policy.

The signed update channel accepts structured blocking-rule data only. It cannot deliver JavaScript, WebAssembly, or other executable extension logic. Executable extension code is packaged with the submitted extension.

Local storage

Protection settings, allowlist/Strict choices, local activity counters, and verified filter-update state may be stored using the browser's extension storage on the user's device.

Private browsing

The Opera release of iShield Extension disables private/incognito browsing access.

Sale or sharing of data

iShield Extension does not sell or share user browsing data because iShield Extension does not transmit that browsing data to its backend.

Changes

If iShield Extension's data practices change, this policy and relevant store disclosures will be updated before a release that introduces those changes.

Contact

For privacy or product questions, use the contact information published on the iShield Extension website.
