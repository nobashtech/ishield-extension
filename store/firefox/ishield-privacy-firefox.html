iShield Extension for Firefox Privacy Policy

Effective: October 5, 2026 · Applies to iShield Extension for Firefox desktop, version 1.0.0.1 and later versions that link to this policy.

Short version: iShield Extension processes the information it needs to protect web pages on your device. It does not send your browsing history, visited URLs, page content, search terms, account information, extension usage, device identifiers, installation identifiers, telemetry, analytics, or advertising identifiers to us or to a third party. Its only extension-initiated remote connection is a fixed HTTPS request used to download signed filter-rule updates.

1. What iShield Extension does

iShield Extension blocks ads and trackers and provides phishing, scam, malware, fingerprinting, cosmetic-filtering, and anti-breakage protections. To perform these functions, Firefox grants iShield Extension access to supported web pages and network-request filtering APIs.

2. Information processed locally

To provide protection, iShield Extension may inspect the current page URL or hostname, network-request details exposed by Firefox's extension APIs, and limited page content needed for cosmetic filtering, anti-adblock handling, phishing/scam checks, and breakage protection. This processing happens locally in your browser.

Settings, allowlists, protection modes, locally calculated blocking counters, and the current verified filter-update state may be stored in Firefox extension storage on your device. iShield Extension does not maintain a remote account or cloud profile for this data.

3. Data iShield Extension does not collect or transmit

iShield Extension does not intentionally collect or transmit personal data or technical/interaction data for storage or processing outside the extension. In particular, iShield Extension does not transmit:

  • browsing history, visited URLs, page content, search terms, or form content;
  • names, email addresses, account credentials, cookies, authentication data, or payment information;
  • device IDs, installation IDs, advertising IDs, or other persistent user identifiers;
  • extension usage analytics, telemetry, crash reports, or behavioral metrics;
  • managed-device, enrollment, family-control, or enterprise-control information.

4. Signed filter updates

iShield Extension periodically checks one fixed public endpoint for updated blocking filters:

https://update.broxme.com/ishield/manifest.json

The extension sends a generic HTTPS GET request only. iShield Extension adds no query parameters, request body, credentials, cookies, referrer, installation identifier, device identifier, browsing information, or telemetry to that request. The extension accepts only a signed network-rule resource, verifies the signature and safety limits locally, and then updates local Declarative Net Request rules.

The update channel cannot deliver JavaScript, WebAssembly, or other executable extension logic. All executable extension code is packaged with the Firefox add-on.

As with any ordinary HTTPS connection, normal network infrastructure may necessarily process connection-level information such as an IP address and standard browser networking metadata. iShield Extension does not read that information from your device, append it to the update request, use it as an identifier, or use the filter-update channel for profiling or analytics.

5. Private browsing

The Firefox release of iShield Extension declares private browsing as not allowed. It does not run in Firefox private windows.

6. Permissions

  • declarativeNetRequest: blocks or redirects unwanted network requests using packaged and signed filter rules.
  • Host access to HTTP and HTTPS pages: provides protection across websites and allows local page-level filtering.
  • scripting: runs packaged cosmetic-filtering and protection code where needed. It is not used to download remote executable code.
  • storage: keeps settings, allowlists, local counters, and verified filter-update state on your device.
  • alarms: schedules filter-update checks and local maintenance.
  • activeTab: allows user-initiated toolbar interactions with the currently active tab, including local protection status and matched-rule information.

7. Retention and deletion

iShield Extension stores only the local extension data required for its features. You can change or clear supported settings from iShield. Removing the extension causes Firefox to remove its extension storage according to Firefox behavior.

8. Sale, advertising, and profiling

iShield Extension does not sell user data, share user data for advertising, inject affiliate tracking, or create profiles of users or their browsing activity.

9. Changes to this policy

If a future version materially changes iShield Extension's data practices, the privacy policy and Firefox data-collection declaration will be updated before that version is released.

10. Contact

For iShield Extension support or privacy questions, use the official iShield Extension website: https://broxme.com/ishield/.
