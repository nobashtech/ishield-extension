# Brave distribution

There is no separate iShield Extension Brave store build. The Chrome Web Store Manifest V3 package is the canonical Brave-compatible package.

For GitHub release convenience, a file named `iShield-Brave-1.0.0.1-compatible.zip` may be published as an exact copy of the Chrome store-ready ZIP. Users should normally install from the Chrome Web Store in Brave so browser-managed updates and store review are retained.
