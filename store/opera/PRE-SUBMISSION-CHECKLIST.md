# iShield Extension — Opera pre-submission checklist

- [ ] Deploy `ishield-privacy-opera.html` at https://broxme.com/ishield/privacy/opera/
- [ ] Verify the privacy URL is public without login and returns HTTP 200.
- [ ] Upload `iShield-Opera-1.0.0.1-store-ready.zip`.
- [ ] Use the title `iShield Extension` — do not put “Opera” in the extension title.
- [ ] Category: Productivity.
- [ ] Paste the summary/description from `OPERA-ADDONS-SUBMISSION.md`.
- [ ] Add the homepage/support URL only where the form requests it.
- [ ] Use the permission explanations from `PERMISSION-JUSTIFICATIONS.md` if review asks.
- [ ] Provide `REVIEWER-NOTES.md` if a reviewer asks about broad host access, packaged scriptlets or filter updates.
- [ ] Keep `iShield-Opera-1.0.0.1-source.zip` available for code-review/reproducibility requests.
- [ ] Choose the intended distribution license/EULA in the Opera submission form; Opera's guidelines say that without a separate EULA, the submission defaults to CC BY-NC-ND 4.0 for end-user licensing.
- [ ] Provide clean Opera screenshots, preferably 612×408 and not above 800×600.
- [ ] Test the unpacked build in current Opera on Windows, macOS and Linux where practical; Opera states accepted extensions may be tested across those platforms.
- [ ] Confirm private browsing remains disabled.
- [ ] Confirm filter endpoint is reachable before submitting.
